# 论文检索与筛选规则

目标是获得去重后的 80–100 篇候选论文，再选择能回答原研究问题的证据进入阅读。
候选论文数量和最终阅读、引用数量分开控制；当前界面可设置目标阅读 5–15 篇。
达到目标后提前停止评分；候选耗尽仍不足时报告实际数量，不强行纳入无关论文。

## 检索

- 首轮生成五个互补方向：基础概念、研究方法、数据与评测、比较研究、局限与挑战。
  查询保留原问题的研究对象、任务、人群和时间约束，并使用学术术语及同义表达。
- 每个查询从 arXiv、Semantic Scholar、PubMed、Crossref 分别请求最多 20 篇。
- 跨来源、跨轮次按规范化 DOI 和标题去重，补充更完整的摘要、日期、PDF 和引用信息。
  已知 DOI 不同的同名论文保留为不同文献。
- 候选不足 80 篇时，即使检索评审模型认为覆盖充分，也继续生成补充查询。默认最多五轮。
- 候选超过 100 篇时按来源和检索轮次均衡压缩，各组内部按下面的粗排优先级取论文。
  这个预选步骤不替代后续与问题相关性的模型评分。
- 停止检索后仍不足 80 篇会返回 `SEARCH_TARGET_NOT_MET`，包含实际数量；来源不可用或主题
  文献过少时不会假造论文、重复计数或强行补齐。没有任何结果沿用 `NO_PAPERS_FOUND`。

## 模型筛选前的粗排

所有进入筛选的候选都会粗排，包括不足或等于 100 篇的列表。粗排不调用模型，当前启发式
权重为标题/摘要与问题的词项匹配 50%、摘要可用性 25%、引用影响力 10%、期刊/会议指标
10%、PDF 链接 5%。英文忽略常见停用词，中文使用双字片段；它只安排优先级，不作为纳入门槛。
引用量使用按发表年限折算后的对数值，避免少数极高引用值支配排序。

来源返回的日期、期刊/会议名称、ISSN、PDF 链接在去重时合并。有 PDF 链接只表示存在可尝试
获取的地址，不代表已经下载或可以提取全文。PubMed/arXiv 未提供引用统计时标记为未知，
不把未知当作真实的零引用；来源覆盖不同，引用指标只作辅助信号。

没有可靠期刊/会议指标时使用中性值，不由模型猜测分区或影响因子。可用 `VENUE_QUALITY_PATH`
指定由用户核对的 JSON 指标表，键为 ISSN 或期刊/会议名称，例如下面的**格式示例**：

```json
{
  "期刊或会议名称": {
    "score": 75,
    "metric": "你选择的指标名称及转换规则",
    "year": 2025,
    "source": "可信指标来源地址"
  }
}
```

`score` 为用户按统一规则换算的 0–100 分，必须附指标名称、年份和来源。系统校验数据结构，
不自动核验指标来源真实性，也不内置任何虚构期刊等级。粗排权重是工程起点，未宣称经过
真实研究任务验证；高引用或高期刊指标不能替代模型对核心相关性的判断。

## 多维评分

模型接收原问题、当前筛选目标、标题、最多 2500 字符摘要、发表日期、来源、DOI、引用数、
期刊/会议信息和已有指标。缺失引用数按未知传入。
每个维度给出 0–5 分，后端按固定权重计算总分，模型不直接决定总分：

| 维度 | 权重 | 评估内容 |
| --- | --- | --- |
| 主题匹配 | 35% | 是否属于问题的核心研究主题，而非只共享关键词或缩写 |
| 问题契合 | 25% | 能否回答具体问题，是否符合任务、研究对象、人群、比较与时间要求 |
| 方法匹配 | 15% | 方法、模型、实验设计与研究问题的联系 |
| 证据强度 | 15% | 摘要中明确描述的理论、实证或综述证据是否可用 |
| 时效性 | 5% | 发表日期及用户时间约束；不因较早发表而排斥相关奠基研究 |
| 信息完整性 | 5% | 摘要及引用元数据是否足够支持判断和引用 |

总分 = 各维度分数 / 5 × 对应百分比之和，取值 0–100。默认需要总分至少 70，且主题匹配、
问题契合分别至少 3/5。模型显式判定范围不符的论文也被排除。高引用量或新近发表不能
补偿核心相关性不足。模型需给出具体匹配或排除理由，不得推断元数据中没有的实验或质量。

每批默认 **5 篇**，按粗排顺序逐批提交，每次模型调用的输出预算为 **6000 tokens**。
每批结束检查标准达标数量，达到用户目标后不提交后续批次。批内编号独立；维度必须齐全且
处于 0–5，重复、未知或不属于当前补评请求的编号忽略。

外层 JSON 截断时尝试保留已完整返回、通过结构校验的逐篇评分。只有缺失或非法记录需要
补评；补评拆成最多 2 篇的小请求，每篇最多补评一次，每个请求仍是 6000 tokens。达到目标后
也不再进行无必要的补评。评分失败的论文不会自动获得分数，不进入阅读。

主筛选总分门槛为 **70**。只有全部候选及其必要补评结束仍不足目标，才从 **65–69 分**的
候选按分数选补充论文。补充论文仍必须满足主题匹配和问题契合各至少 3/5、模型判定范围
符合；核心要求不放宽。补充入选记录标记为 `supplemental`，前端和写作证据明确保留此信息。
通过主门槛的论文优先，数量不足时允许实际阅读数量小于目标。

已评估、通过门槛的论文按总分排序，取用户指定数量。提前停止意味着没有保证这是所有候选
中总分最高的 N 篇。没有有效评分返回
`SCREENING_FAILED`；有评分但没有合格论文返回 `NO_RELEVANT_PAPERS`。

## 证据和前端

多轮阅读只保留本轮入选论文的证据；写作提示中的证据也以当前入选列表过滤，避免被排除的
旧论文继续进入参考文献。报告仍要求仅列出正文实际引用的来源。

API 和历史研究结果保留入选列表、六维评分、综合分、筛选理由、主筛选/补充层级和统计。
统计分别包含候选数量、提交评估数量、有效评分、评分失败、未评估、主筛选达标、补充数量、
目标和实际阅读数量；`attempted = scored + failed`，`candidates = attempted + not_evaluated`。
达到目标后剩余论文为 `not_evaluated`，评分为 null，不能解释成低分、无关或评分失败。
模型响应日志记录批次、论文 ID、finish_reason、返回字符数及接口提供的输入/生成/推理
token 用量；不记录推理正文。接口未提供用量时记录 null，不把缺失统计当作零。
前端显示百分制分数和分项，并保留旧历史记录的五分制显示。候选列表可查看全部最多 100 篇，
它与“筛选后的论文”列表不同：报告证据来自后者。

## 配置

```text
MAX_SEARCH_ROUNDS=5
SEARCH_RESULTS_PER_SOURCE=20
MIN_CANDIDATE_PAPERS=80
MAX_CANDIDATE_PAPERS=100
SCREENING_MIN_SCORE=70
SCREENING_SUPPLEMENT_MIN_SCORE=65
SCREENING_BATCH_SIZE=5
SCREENING_MAX_TOKENS=6000
VENUE_QUALITY_PATH=
```

修改本地配置后重启后端以重新加载。检索与模型评分的真实质量仍取决于检索源可用性、问题
表达及模型判断；本次自动测试验证数量、评分和证据路由规则，没有编造或宣称真实检索效果。
