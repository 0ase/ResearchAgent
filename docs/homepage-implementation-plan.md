# B1GONE 首页基础版施工计划

日期：2026-10-11。设计依据：`docs/design/homepage/b1gone-homepage-v3.png`。先完成可使用的基础页面，再在此基础上添加角色回应、线束探索、节点联动和转场动效。

## 范围与约束

- 首页采用灰蓝画布、黑色顶部导航、奶白按键、像素中文和现有 B1GONE 标志。
- 左侧为标志、两行简介和五个节点的职责介绍；右侧为已放大的正面像素机器人、英文 Transformer 用例及四条彩色子问题，下面为研究问题输入框与开始研究按钮。
- 黑色入射线贯穿至屏幕左缘，分隔左侧简介和节点列表。小屏调整为单列，保证文字与输入框可读。
- 首页可使用非常轻的静态 CRT 边缘余晖和扫描线；会话页面不增加屏幕特效。
- 本轮首页不添加 ASCII 解码、角色动作、可点击子问题或页面转场。保留会话页已经实现的输入框与齿轮动效。
- 复用现有研究、历史、报告、文献和设置功能。不更改后端核心路由、工作流、配置默认值、数据库结构或真实配置文件，不增加依赖。
- 保留工作区已有未提交修改及设计图，不自动提交或推送。`docs/evaluation-implementation-plan.md` 不属于本次施工。

## 接口及新增函数

本次没有新增后端接口。沿用：

| 功能 | 现有接口或函数 | 首页处理 |
|---|---|---|
| 开始研究 | `App.beginResearch` → `POST /api/research/stream` | 传入用户实际输入，切换至会话页，由现有 SSE 流更新任务 |
| 设置 | `SettingsDialog` → `GET/PUT /api/settings` | 打开已有弹窗；密钥与保存规则保持原有实现 |
| 连接与历史 | 现有 `/health` 与历史读取 | 沿用 App 的连接过程，不额外重复请求 |
| 文档 | 新增 `DocumentationDialog` | 本地帮助内容及进入工作台入口 |
| GitHub | 普通外部链接 | 打开 `https://github.com/0ase/ResearchAgent` |

新增前端函数/组件：

- `usePageNavigation()`：依据路径识别首页 `/` 与会话页 `/research`，通过 History API 和 `popstate` 处理导航；保留 `?demo=1` 等查询参数。
- `HomePage()`：展示首页与表单，校验空白问题及长度，处理 Enter、Shift+Enter 与中文输入法组合状态。表单不预填示例问题。
- `HomeMascot()`：以独立 SVG 绘制像素头、输入线、英文用例、四条彩色子问题；保留后续替换和动画入口。
- `DocumentationDialog()`：用现有 Dialog 展示使用说明；不增加服务端依赖。
- `App` 中增加首页提交与返回首页入口；任务、设置与请求状态仍由原 App 持有，切换页面不重建研究任务。

## 设计规则与核对

- 颜色：灰蓝 `#8FA1A4`、墨黑 `#151A1B`、导航黑 `#202223`、奶白 `#E7DEC5`、细线 `#6C7C7F`。
- 字体：首页中文和示例文字使用已随项目提供的 Fusion Pixel；标志沿用 Wordmark SVG；帮助说明与综述正文使用便于阅读的中文字体。
- 桌面布局：左列约 36%，右列约 60%，中间留白约 4%；入射线与左栏分隔位置共享几何关系。右侧以角色为视觉中心，按键维持现有奶白色。
- 手机布局：标志和简介在上，机器人/示例及输入区居中，职责介绍随后展示；保持可访问标签和 44px 触控目标。
- 依据用户定稿保留像素艺术字、黑色线束和奶白键帽，不增加宣传卡片、数据计数、额外导航或虚构研究进度。

## 实施及验收

1. 先保存本计划，再编写前端代码。
2. 构建检查 TypeScript 和打包。
3. 浏览器验证首页布局、文档与设置入口、GitHub 目标、空白输入、中文输入法、提交后真实接口载荷与会话切换、前进后退、小屏无横向溢出。
4. 使用拦截接口与演示模式验证流程，不创建付费研究任务或保存实际配置。
5. 运行现有会话、联调与动效检查，确认侧栏、文献宽度、报告与追问未受影响。
6. 查看桌面和小屏截图，按定稿图调整比例与间距，提供本机预览地址。
