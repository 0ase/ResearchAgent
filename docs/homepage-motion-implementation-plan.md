# B1GONE 首页动效施工计划

日期：2026-10-11。基础提交：6985450。范围为用户已采纳的五项首页交互，保留现有布局、配色、Michroma 英文及会话功能。

## 行为与时序

1. 机器人：空闲偶尔眨眼；聚焦或输入时看向左侧；启动转场时天线响应。采用离散帧，不持续晃动整个角色。
2. 彩色子问题：悬停/键盘聚焦时略展开并展示完整问题；点击或按 Enter/Space 填入中文研究问题、聚焦输入框，不自动提交。四个完整问题沿用已记录的真实 Transformer 拆解。
3. 左侧节点：悬停、聚焦或点击时，机器人面罩显示相应工具图形；writer 有短光标提示。它是职能展示，不表示正在运行该节点。
4. 奶白按键：悬停及键盘聚焦时短暂 ASCII 解码；文字宽度和可访问名称稳定。按下时保留机械下沉反馈。动画状态仅保留在按钮组件中。
5. 开始研究：冻结本次实际输入，约 360ms 内播放文字沿黑线进入、彩色束收拢，再沿用原研究提交函数。会话页短暂以同色线条承接现有研究过程，约 400ms 后移除。重复点击/Enter 不会重复提交；转场中离开首页则清理待提交定时器。

## 动态效果边界

- 新增动效仅用于首页及一次短会话进入提示，会话页不添加 CRT、闪屏或背景粒子。
- 减少动态效果时不解码、不眨眼、不等待退出转场；子问题填入、节点职能说明及真实研究入口仍可用。
- 页面隐藏或文档/设置弹窗打开时暂停装饰动画；定时器在组件卸载后清理。
- 不将示例、随机 ASCII 或视觉动画当作实际研究输入、后端进度或模型结果。
- 不增加依赖、后端接口或配置修改；不调用真实模型来测试动效。不自动提交本轮改动。
