# 会话侧边栏调宽施工计划

## 范围与视觉约定

会话页左栏右边界提供拖动调宽。沿用灰蓝画布 `#8fa1a4`、墨黑 `#151a1b`、黑色侧栏 `#202223`、奶白按键 `#e7dec5` 和分割线 `#6c7c7f`；保留现有像素控件字体、等宽计数与普通中文报告正文。分割线中央采用与右侧文献栏相同的细小拖动柄，悬停或键盘聚焦后加强显示。

```text
研究记录 [可调宽] | 研究过程 / 报告 / 输入框 | 文献 [已有调宽]
```

内容继续左对齐，不新增卡片、动效或装饰。左栏最小 220px、最大 480px，并根据窗口与文献栏实际宽度缩小上限，为正文和输入框保留至少 420px。拖动中仅更新 CSS 宽度，松开后保存本页偏好。收起、展开、切换首页和会话后恢复；缩小窗口时限制实际宽度，放大后恢复偏好。700px 以下继续使用现有抽屉，不显示桌面拖动柄。
