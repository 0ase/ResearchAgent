# Windows 双击启动施工计划

## 范围

新增根目录 `启动B1GONE.bat`，调用 `scripts/start_project.ps1`。普通启动使用 `backend.main:app`；传入 `-Observe` 使用 `evaluation.observed_app:app`。两者均通过 Conda 的 BIGONE 环境运行后端，前端沿用 `web` 中的 Vite、5173 端口和现有代理，后端保持 3000 端口。不改变后端路由、模型配置、数据库结构或研究流程。

## 行为

- 自动定位 BAT 所在项目，检查 Conda、BIGONE 环境、Node/npm 与已安装的前端依赖；缺失依赖显示安装指令，不自动安装。
- 启动前检查端口。已有手动启动的服务占用端口时提示停止原服务，不替换或终止它们。
- 后台启动两个子服务并将输出写入本机 `logs`；保留控制窗口，等待后端健康检查与前端页面可用，再打开非演示页面。
- 同一项目重复双击时识别已有启动器；就绪时打开已有页面，不重复启动。
- 启动失败、控制窗口 Enter/Q 退出或 Ctrl+C 时清理本次启动的服务进程树；提供 `-Stop` 处理控制窗口意外关闭后仍运行的服务。
- 使用本机进程身份及启动时间记录清理目标，不关闭任意占用同一端口的进程。状态及日志属于 Git 忽略的 `logs` 目录。
- 提供 `-CheckOnly` 检查依赖，`-NoBrowser` 跳过浏览器打开；允许显式指定 Conda/npm 路径，兼容双击时 PATH 与终端不同的情况。

## 文件结构差异

- 新增 `启动B1GONE.bat`：ASCII 内容的双击入口，保持路径引用并传递参数。
- 新增 `scripts/start_project.ps1`：环境发现、检查、后台服务、健康等待、停止与重复启动管理。
- 新增 `scripts/tests/test_project_launcher.ps1`：路径含空格/中文、服务参数、进程归属、HTTP 就绪与进程树关闭测试。
- 修改根 README 和 web README：双击使用方式、普通/观测模式及指标归属说明。
- 本文记录施工范围与验证结果。

## 指标发布语义

现有 `/metrics/summary.json` 来自 `web/public/metrics/summary.json`，并且该文件、数据库、日志及评测原始记录都被 Git 忽略。GitHub clone/源码 ZIP 不携带本机实测值；首次没有快照时显示暂无统计。用户运行真实任务并执行更新脚本后得到自己的统计。

Vite 构建会将当时 public 中的快照复制到 dist。如果分发该构建目录或部署该网站，访问者会看到其中的构建时快照。官方基准应另行冻结测试集、标注和版本，并明确标为官方评测；本次不将本机开发记录伪装成官方基准或提交到 Git。

## 验证及提交

验证 PowerShell 5.1 与 BAT 语法、BIGONE 环境预检查、已有端口占用的处理，以及隔离测试子进程的创建/退出和端口释放。既有用户服务不重启，不调用研究模型。本轮提交同时包含前面已完成但未提交的首页指标和左栏调宽；原先已有的 `docs/evaluation-implementation-plan.md` 不属于本轮修改，不纳入提交。

## 完成记录

2026-10-12：BAT 和 PowerShell 启动器已完成。PowerShell 5.1 语法解析通过；真实环境 `-CheckOnly -Observe` 通过，并识别现有 3000/5173 服务占用，没有启动或关闭它们。完整测试模式 `scripts/tests/test_project_launcher.ps1 -RealServices` 的 22 项检查通过：含空格/中文路径、两种后端入口、健康等待、状态文件、进程身份、超时、真实 BIGONE 观测后端和 Vite 在独立端口启动/关闭，以及 BAT 参数转发。停止并发清理处理改进后再次通过 17 项隔离检查。

启动器子服务使用隐藏窗口并记录输出，控制窗口保留启动和关闭状态。状态文件对 Windows 文件共享限制进行有限重试，读取方拒绝不完整内容。启动失败会尝试清理两个已管理进程；重复停止不会因为某个进程先退出而漏掉另一个服务。

Git 检查确认本机 summary、数据库、日志、观测记录和 dist 都没有跟踪且被忽略；源码下载不携带本机读数。README 已补充 React 启动方式、双击入口、指标归属与构建时快照的分发区别。
