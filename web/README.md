# B1GONE 研究工作台

React + TypeScript + Vite + Tailwind CSS v4。默认连接现有 FastAPI 后端；研究、历史、追问、报告和文献均采用真实接口数据。已确认的视觉与侧栏交互保留。

## 启动

第一个终端从项目根目录启动 BIGONE 后端：

```powershell
cd D:\BIGONE
.\scripts\start_backend.ps1 -Port 3000 -Reload
```

第二个终端启动前端：

```powershell
cd D:\BIGONE\web
npm install
npm run dev
```

访问 http://127.0.0.1:5173/ 进入首页。首页采用已确认的灰蓝画布、黑色导航和奶白按键；提交研究问题后进入 /research 工作台，并加载真实研究历史。也可以直接访问 http://127.0.0.1:5173/research 。Vite 将 /api 和 /health 代理到 http://127.0.0.1:3000，不需要改变后端研究路由或增加 CORS。若使用其他后端端口，只调整 web/vite.config.ts 中两个代理 target。开发代理不适用于 npm run preview 或独立生产部署。

## 首页基础版

- 顶部“文档”打开本地使用说明，“设置”与对话页共用环境配置弹窗（演示模式也可访问）；右侧 GitHub 图标打开项目仓库。
- 左侧为 B1GONE 标志和节点职责，右侧为独立 SVG 绘制的像素机器人与 Transformer 拆解示例；示例内容不会自动填入或提交。
- 黑色入射线在桌面布局中贯穿到屏幕左缘，分隔简介与节点列表；小屏使用单列排布及可读的四个子问题。
- 首页支持 Enter 提交、Shift + Enter 换行，并避免输入法确认文字时误提交。输入为空或只有空白时，点击“开始研究”或按 Enter 直接进入空的对话工作台并聚焦输入框，保留历史，不发起研究。点击会话页 B1GONE 标志返回首页；同一页内前进、后退保留研究状态，不重复发起请求。
- 首页空输入框复用对话页的问题轮播：随机 ASCII 逐字生成中文问题，完整显示约 5.9 秒后逐字删除并切换；保留 `|<` 光标。聚焦、已有输入、提交中、弹窗打开、页面隐藏或减少动态效果时停用动画。轮播内容仅作提示，不会写入输入值或自动发起研究。
- 首页使用可见的 4px 扫描线、椭圆暗角与玻璃内缘反光表现 CRT 曲面，标志及奶白按键带柔和余晖；低亮度刷新带约 14 秒扫过一次。装饰层不拦截点击，不改变文字或控件位置，对话页保持普通阅读显示。机器人偶尔眨眼，聚焦输入框时看向输入侧；奶白按键悬停或聚焦时短暂进行 ASCII 解码，按下时轻微下沉。
- 悬停或聚焦彩色子问题可查看完整问题，点击或使用 Enter/Space 将对应的真实中文子问题填入输入框，不会自动提交。悬停、聚焦或点击左侧节点，面罩显示该职能的工具图形；writer 的光标以低帧率闪烁。这些是首页职能展示，不表示后端正在执行某个节点。
- 点击“开始研究”后冻结本次问题，约 360ms 的退出动效结束后只提交一次，进入会话时以短线条承接研究过程。转场中离开首页会清理待提交动作；研究已提交后的状态与停止机制沿用原实现。
- 系统开启“减少动态效果”时保留交互功能并直接进入研究，不播放装饰动效。页面隐藏或设置/文档弹窗打开时暂停装饰计时。原有会话页动效和阅读布局保留。
- 首页动效施工范围与验证见 ../docs/homepage-motion-implementation-plan.md。
- 首页首屏保持原样，下滑查看“运行与评测”：P50/P95/P99、平均耗时、token、任务终态、阅读结果率、RAG 与证据指标。它读取真实运行的聚合快照，演示任务不计入；缺少完整 usage 或金标准显示 N/A，完整口径可展开查看。
- 施工计划与文件结构差异见 ../docs/homepage-implementation-plan.md。核心后端接口与配置未改动。

## 使用

- Windows 可在项目根目录双击 `启动B1GONE.bat`，自动启动前后端并打开真实首页。保留启动窗口，Enter/Q 或 Ctrl+C 退出；`启动B1GONE.bat -Observe` 启用完整指标观测，`-Stop` 关闭启动器管理的服务。脚本只管理自己启动的进程；已有手动服务占用端口时，先在原终端停止。

- 输入研究问题开始新研究，最多 2000 字；Enter 提交，Shift + Enter 换行。
- 阶段节点显示真实调度记录和返回结果，允许同一阶段多次出现；现有后端未发送精确节点生命周期，界面不模拟开始时间或进度百分比。
- 完成后过程折叠保留，报告支持 Markdown 标题、表格、列表和代码块。点击已关联的 [Source ID]、直接来源编号或 DOI 引用打开对应文献。
- 文献栏仅列出返回有效阅读内容的文献。参考文献章节单独出现不计正文引用；未识别引用格式显示“已确认引用”，不会补齐到目标数量。
- 摘要可展开，原文打开有效 PDF 或 DOI 链接，缺失链接明确标注。
- 完成研究后输入框用于追问当前研究；“新建研究”开始新任务。追问失败后的“重试追问”复用 message_id，配合现有后端去重。
- 历史恢复服务器已经保存的报告、阅读内容和调度记录；细粒度历史过程缺失不会被示例数据补造。
- “停止”断开研究流，当前页保留已收到的记录。后端沿用现有流清理机制，未增加独立取消确认、失败/停止记录持久化或运行任务恢复接口。
- 侧栏在设置右侧收起；研究记录栏和文献栏均可拖动边界调宽，或聚焦边界后使用左右方向键（Shift 加速、Home 最窄、End 最宽）。左栏宽度在本页收起/展开和首页/会话切换时保留，调整时为报告保留空间；拖动中 Esc 取消本次调整。手机端研究记录继续使用抽屉，Esc 关闭。
- 空输入框轮播预设问题：随机 ASCII 字符逐字解码成问题，完整显示约 5.9 秒后逐字删除并切换。聚焦、已有输入、任务执行、弹窗打开或页面隐藏时暂停；示例文字不会作为输入提交。设置齿轮悬停或键盘聚焦时以每秒约 6 帧顺时针转到 180°并停住，移开或失焦时逆时针回到原位，每程约 1 秒。系统启用“减少动态效果”时保留静态显示。
- 导出下载服务器返回的原始 Markdown，保留报告实际参考文献。

## 设置

“设置”读取独立 GET /api/settings，并通过 PUT /api/settings 保存白名单字段到项目根目录 .env。只允许本机来源访问，写入要求本机 Origin 和专用请求头；没有增加公网配置管理权限。

密钥仅显示是否配置，输入留空保留原值，勾选清除才移除文件密钥。秘密不存浏览器 localStorage，也不使用 VITE_*。保存后重启后端生效；运行中任务继续使用启动时的配置。系统环境变量仍优先于文件，界面标注覆盖字段和当前生效值。

路径、数据库和日志参数只读，不修改 Settings 默认值及现有模型密钥选择规则。需从项目根目录启动后端，避免现有相对 .env 加载机制指向其他目录。

## 更新指标

在项目根目录的 BIGONE 环境运行 `python -m evaluation.update_metrics`，再点击首页指标区的“刷新读数”。可使用 `--watch --interval 30` 持续离线更新；不会启动研究或调用模型。

历史日志仅记录筛选/分析的部分 usage，完整平均 token 和 RAG 质量需要新观测记录与金标准。下次可用 `python -m uvicorn evaluation.observed_app:app --host 127.0.0.1 --port 3000 --reload --reload-dir backend --reload-dir evaluation` 启动相同后端并附加独立观测；原启动方式保持可用。本次没有重启后端或改变核心接口。

脚本、标注格式和指标口径见 ../evaluation/README.md；施工范围与文件差异见 ../docs/homepage-metrics-implementation-plan.md。本地明细、实际标注和生成快照已 Git 忽略，前端只加载聚合信息。

GitHub clone 或源码下载不包含开发者的本机指标，新用户首次没有快照时显示暂无统计；用户运行和生成快照后看到自己这份项目的读数。构建前存在的 `web/public/metrics/summary.json` 会被复制到 `web/dist`，所以分发构建目录/静态网站时显示其中的构建时快照。已构建的 dist 需要重新构建才会包含后来更新的 public 快照。当前没有单独发布官方基准数据。

## 演示与检查

访问 http://127.0.0.1:5173/?demo=1 可独立查看首页并提交演示研究；http://127.0.0.1:5173/research?demo=1 直接进入原有工作台示例。研究、历史和追问不访问后端或调用模型，报告与论文为虚构数据。“设置”仍访问本机配置接口，可以管理真实环境配置；需启动后端。演示时长与结果折叠保留在“演示选项”中。

```powershell
npm run build
npm run test:e2e
```

浏览器测试默认使用本机 Edge（可设置 PLAYWRIGHT_CHANNEL=chrome），联调测试拦截 API 请求，无模型费用。截图和结果位于根目录 tmp，不进入版本控制。后端新增配置测试使用临时 env 文件，不改真实配置。

接入契约与文件变更见 ../docs/frontend-backend-integration-plan.md。核心研究路由、研究工作流、配置默认值及数据库结构保持不变。

## 字体

常驻控件使用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 的 12px 简体中文比例字体（2026.09.25），字体采用 SIL OFL 1.1，文件与上游许可位于 public/fonts/；报告正文使用系统中文字体。品牌字与图标为代码绘制的 SVG。

首页机器人两侧的英文问题使用 [Michroma](https://github.com/google/fonts/tree/main/ofl/michroma)，用户确认作为 Eurostile Extended 的替代字体。字体及 Michroma-OFL.txt 保存在 public/fonts/，通过本地 @font-face 加载；桌面与小屏共用。换字体后调整了桌面英文字号以避免遮挡和边缘裁切，中文、节点名称及其他控件字体保持原样。
