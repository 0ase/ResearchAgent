# B1GONE 研究工作台

React + TypeScript + Vite + Tailwind CSS v4。默认连接现有 FastAPI 后端；研究、历史、追问、报告和文献均采用真实接口数据。已确认的视觉与侧栏交互保留。

## 启动

第一个终端从项目根目录启动 BIGONE 后端：

```powershell
cd D:\BIGONE
.\scripts\start_backend.ps1 -Port 3000 -Reload
```

第二个终端启动前端：

```powershell
cd D:\BIGONE\web
npm install
npm run dev
```

访问 http://127.0.0.1:5173/ 。默认显示空白提问页，并加载真实研究历史。Vite 将 /api 和 /health 代理到 http://127.0.0.1:3000，不需要改变后端研究路由或增加 CORS。若使用其他后端端口，只调整 web/vite.config.ts 中两个代理 target。开发代理不适用于 npm run preview 或独立生产部署。

## 使用

- 输入研究问题开始新研究，最多 2000 字；Enter 提交，Shift + Enter 换行。
- 阶段节点显示真实调度记录和返回结果，允许同一阶段多次出现；现有后端未发送精确节点生命周期，界面不模拟开始时间或进度百分比。
- 完成后过程折叠保留，报告支持 Markdown 标题、表格、列表和代码块。点击已关联的 [Source ID]、直接来源编号或 DOI 引用打开对应文献。
- 文献栏仅列出返回有效阅读内容的文献。参考文献章节单独出现不计正文引用；未识别引用格式显示“已确认引用”，不会补齐到目标数量。
- 摘要可展开，原文打开有效 PDF 或 DOI 链接，缺失链接明确标注。
- 完成研究后输入框用于追问当前研究；“新建研究”开始新任务。追问失败后的“重试追问”复用 message_id，配合现有后端去重。
- 历史恢复服务器已经保存的报告、阅读内容和调度记录；细粒度历史过程缺失不会被示例数据补造。
- “停止”断开研究流，当前页保留已收到的记录。后端沿用现有流清理机制，未增加独立取消确认、失败/停止记录持久化或运行任务恢复接口。
- 侧栏在设置右侧收起；文献栏可拖动或通过方向键调宽；窄屏使用抽屉，Esc 关闭。
- 导出下载服务器返回的原始 Markdown，保留报告实际参考文献。

## 设置

“设置”读取独立 GET /api/settings，并通过 PUT /api/settings 保存白名单字段到项目根目录 .env。只允许本机来源访问，写入要求本机 Origin 和专用请求头；没有增加公网配置管理权限。

密钥仅显示是否配置，输入留空保留原值，勾选清除才移除文件密钥。秘密不存浏览器 localStorage，也不使用 VITE_*。保存后重启后端生效；运行中任务继续使用启动时的配置。系统环境变量仍优先于文件，界面标注覆盖字段和当前生效值。

路径、数据库和日志参数只读，不修改 Settings 默认值及现有模型密钥选择规则。需从项目根目录启动后端，避免现有相对 .env 加载机制指向其他目录。

## 演示与检查

访问 http://127.0.0.1:5173/?demo=1 可独立使用原型示例，不访问后端，也不调用模型。演示中的报告与论文为虚构数据。

```powershell
npm run build
npm run test:e2e
```

浏览器测试默认使用本机 Edge（可设置 PLAYWRIGHT_CHANNEL=chrome），联调测试拦截 API 请求，无模型费用。截图和结果位于根目录 tmp，不进入版本控制。后端新增配置测试使用临时 env 文件，不改真实配置。

接入契约与文件变更见 ../docs/frontend-backend-integration-plan.md。核心研究路由、研究工作流、配置默认值及数据库结构保持不变。

## 字体

常驻控件使用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 的 12px 简体中文比例字体（2026.09.25），字体采用 SIL OFL 1.1，文件与上游许可位于 public/fonts/；报告正文使用系统中文字体。品牌字与图标为代码绘制的 SVG。
